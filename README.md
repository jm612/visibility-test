# Visibility Test

Repo de prueba creado el 2026-04-14 para verificar visibilidad de repos bajo la organizacion Urpeailab.

## Contexto

La cuenta personal `durquijop` esta marcada por GitHub (shadow ban): no aparece en busquedas publicas. Este repo se crea en la organizacion para validar si los repos bajo `Urpeailab/` son visibles para miembros del equipo independientemente del flag en la cuenta personal.

## Test para el equipo

Si podes ver este repo, avisale a Diego. Sobre todo:

1. Podes abrirlo en el navegador sin estar loggeado: https://github.com/Urpeailab/visibility-test
2. Te aparece al buscar "Urpeailab" en GitHub search
3. Podes clonarlo: `git clone https://github.com/Urpeailab/visibility-test.git`

Si alguno de los 3 falla, el flag afecta a toda la organizacion y hay que escalar con GitHub Support.
